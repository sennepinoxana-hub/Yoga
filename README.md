# Douceur Yoga

Page statique bilingue (français/russe) prête pour GitHub Pages.

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub, par exemple `douceur-yoga`.
2. Téléversez **tout le contenu de ce dossier**, y compris le dossier `assets`.
3. Dans le dépôt, ouvrez **Settings → Pages**.
4. Sous **Build and deployment**, sélectionnez **Deploy from a branch**, puis la branche `main` et le dossier `/(root)`.
5. Enregistrez : GitHub affichera ensuite l'adresse publique de votre page.

La page n'enregistre aucune donnée : la demande est envoyée directement à WhatsApp au numéro configuré.
